空间测量

选择测量工具，左键添加点，右键结束。距离按确认的点击点累计；高度差、三角测量和方位角在第二次点击后结束。切换工具会结束当前测量，已完成的结果保留，点击「清除结果」全部移除。

示例源码

核心功能​

多种测量模式​

提供六种专业测量工具：

  • 空间距离测量：测量两点之间的直线距离（不考虑地形）
  • 地表距离测量：沿当前已加载地形采样得到近似距离
  • 地表面积测量：计算经纬度多边形的球面投影面积，不含地形起伏
  • 高度差测量：测量两点之间的垂直高度差
  • 三角测量：同时测量水平距离、高度差和空间距离
  • 方位角测量：测量两点之间的方位角和距离

交互式测量​

直观的用户交互体验：

  • 鼠标交互：单击添加测量点，右键结束测量
  • 实时预览：鼠标移动时实时显示测量线段和结果
  • 可视化标注：清晰显示测量点、线段、文字标注
  • 多段测量：支持连续添加多个测量点
  • 结果展示：自动计算并显示测量结果（米/千米、平方米/平方公里）

精确计算​

空间距离使用三维直线距离，高度差使用椭球高之差。三角测量中的水平距离沿用两点投影到椭球后的弦长。地表距离每段采样 20—200 个点，属于近似值；面积是球面投影面积，不是坡面面积。计算时保留精度，仅在显示时取小数。

  • 空间距离：三维欧氏距离计算
  • 大地测量：使用椭球体进行精确的地表距离计算
  • 地形采样：使用 globe.getHeight 读取已加载地形；缺失高度采用端点线性插值
  • 面积计算：Turf 计算球面投影面积，至少需要三个顶点
  • 方位角计算：基于大地坐标的方位角计算

measureLineSpace(): void {
    this.finishMeasure();
    this.bMeasuring = true;
    this.onMeasureStart?.();

    const positions: Cartesian3[] = [];
    let poly: Entity | null = null;
    this.stopPreview = () => {
      if (positions.length) positions.pop();
      if (positions.length < 2 && poly) this.viewer.entities.remove(poly);
    };
    let distance = 0;

    this.handler = new ScreenSpaceEventHandler(this.viewer.scene.canvas);

    // 监听鼠标移动事件
    this.handler.setInputAction((movement: { endPosition: Cartesian2 }) => {
      // 获取鼠标位置的三维坐标
      let cartesian: Cartesian3 | undefined = this.viewer.scene.pickPosition(
        movement.endPosition,
      );
      if (!cartesian) {
        const ray = this.viewer.camera.getPickRay(movement.endPosition);
        if (ray) {
          cartesian = this.viewer.scene.globe.pick(ray, this.viewer.scene);
        }
      }

      if (cartesian && positions.length >= 2) {
        positions[positions.length - 1] = cartesian;
        if (!poly) {
          // 创建线实体
          poly = this.createPolyline(positions, Color.CHARTREUSE, 2);
        }
      }
    }, ScreenSpaceEventType.MOUSE_MOVE);

    // 监听单击事件
    this.handler.setInputAction((movement: { position: Cartesian2 }) => {
      let cartesian: Cartesian3 | undefined = this.viewer.scene.pickPosition(
        movement.position,
      );
      if (!cartesian) {
        const ray = this.viewer.camera.getPickRay(movement.position);
        if (ray) {
          cartesian = this.viewer.scene.globe.pick(ray, this.viewer.scene);
        }
      }

      if (cartesian) {
        if (positions.length === 0) {
          positions.push(cartesian.clone());
        } else {
          positions[positions.length - 1] = cartesian.clone();
        }
        positions.push(cartesian.clone());
        if (!poly) poly = this.createPolyline(positions, Color.CHARTREUSE, 2);

        // 计算距离增量
        const distanceAdd = this.getSpaceDistance(positions);
        distance += distanceAdd;

        // 添加标注
        const textDistance =
          (distance > 1000
            ? `${(distance / 1000).toFixed(3)}千米`
            : `${distance.toFixed(2)}米`) +
          `\n(+${
            distanceAdd > 1000
              ? `${(distanceAdd / 1000).toFixed(3)}千米`
              : `${distanceAdd.toFixed(2)}米`
          })`;

        const entity = this.viewer.entities.add({
          name: "空间直线距离",
          position: positions[positions.length - 1],
          point: {
            pixelSize: 5,
            color: Color.RED,
            outlineColor: Color.WHITE,
            outlineWidth: 2,
            heightReference: HeightReference.NONE,
          },
          label: {
            text: textDistance,
            font: "18px sans-serif",
            fillColor: Color.CHARTREUSE,
            style: LabelStyle.FILL_AND_OUTLINE,
            outlineWidth: 2,
            verticalOrigin: VerticalOrigin.BOTTOM,
            pixelOffset: new Cartesian2(20, -20),
            disableDepthTestDistance: Number.POSITIVE_INFINITY,
            heightReference: HeightReference.NONE,
          },
        });
        this.measureIds.push(entity.id);
      }
    }, ScreenSpaceEventType.LEFT_CLICK);

    // 监听右键结束测量
    this.handler.setInputAction(() => {
      this.finishMeasure();
    }, ScreenSpaceEventType.RIGHT_CLICK);
  }

地表距离测量实现​

每次点击更新确认点，再执行 distance = this.calculateGroundDistance(positions, distance)。数组末尾保留一个预览点，所以本段使用倒数第三和倒数第二个点：

private calculateGroundDistance(
    positions: Cartesian3[],
    distance: number,
  ): number {
    if (positions.length > 2) {
      const positions_: Cartographic[] = [];
      const sp = Cartographic.fromCartesian(positions[positions.length - 3]);
      const ep = Cartographic.fromCartesian(positions[positions.length - 2]);
      const geodesic = new EllipsoidGeodesic();
      geodesic.setEndPoints(sp, ep);
      const s = geodesic.surfaceDistance;

      positions_.push(sp);
      const num = Math.max(20, Math.min(200, Math.floor(s / 100)));

      // 插值获取中间点
      for (let i = 1; s > 0.000001 && i < num; i++) {
        const res = geodesic.interpolateUsingSurfaceDistance(
          (s / num) * i,
          new Cartographic(),
        );
        res.height =
          this.viewer.scene.globe.getHeight(res) ??
          sp.height + ((ep.height - sp.height) * i) / num;
        positions_.push(res);
      }
      positions_.push(ep);

      // 计算总距离
      let distanceAdd = 0;
      for (let ii = 0; ii < positions_.length - 1; ii++) {
        geodesic.setEndPoints(positions_[ii], positions_[ii + 1]);
        const d = geodesic.surfaceDistance;
        distanceAdd += Math.sqrt(
          d ** 2 + (positions_[ii + 1].height - positions_[ii].height) ** 2,
        );
      }

      distance += distanceAdd;

      // 添加标注
      const textDistance =
        (distance > 1000
          ? `${(distance / 1000).toFixed(3)}千米`
          : `${distance.toFixed(2)}米`) +
        `\n(+${
          distanceAdd > 1000
            ? `${(distanceAdd / 1000).toFixed(3)}千米`
            : `${distanceAdd.toFixed(2)}米`
        })`;

      const entity = this.viewer.entities.add({
        name: "地表距离",
        position: positions[positions.length - 1],
        point: {
          pixelSize: 5,
          color: Color.RED,
          outlineColor: Color.WHITE,
          outlineWidth: 2,
        },
        label: {
          text: textDistance,
          font: "18px sans-serif",
          fillColor: Color.GOLD,
          style: LabelStyle.FILL_AND_OUTLINE,
          outlineWidth: 2,
          verticalOrigin: VerticalOrigin.BOTTOM,
          disableDepthTestDistance: Number.POSITIVE_INFINITY,
          pixelOffset: new Cartesian2(20, -20),
        },
      });
      this.measureIds.push(entity.id);
    }
    return distance;
  }

面积计算实现​

使用 Turf 计算球面投影面积，经度跨越日期变更线时先展开；不计入高程，不支持自相交边界：

import { area as polygonArea, polygon } from '@turf/turf';

private getArea(points: Array<{ lon: number; lat: number }>): number {
    if (points.length < 3) return 0;
    const ring: number[][] = [];
    for (const point of points) {
      let lon = point.lon;
      const previous = ring.at(-1)?.[0];
      if (previous !== undefined) {
        while (lon - previous > 180) lon -= 360;
        while (lon - previous < -180) lon += 360;
      }
      ring.push([lon, point.lat]);
    }
    ring.push([...ring[0]]);
    // 球面投影面积，不包含地形起伏。
    return polygonArea(polygon([ring])) / 1000000;
  }

方位角计算​

使用 WGS84 椭球测地线的起点方位角，正北为 0°，顺时针增加；同一点返回 0°：

private courseAngle(
    lngA: number,
    latA: number,
    lngB: number,
    latB: number,
  ): number {
    const start = Cartographic.fromDegrees(lngA, latA);
    const end = Cartographic.fromDegrees(lngB, latB);
    if (start.longitude === end.longitude && start.latitude === end.latitude)
      return 0;
    const heading = CesiumMath.toDegrees(
      new EllipsoidGeodesic(start, end).startHeading,
    );
    return Number(((heading + 360) % 360).toFixed(2));
  }

const s = geodesic.surfaceDistance;

  1. 缓存采样结果
private heightCache = new Map<string, number>();

private sampleHeight(cartographic: Cartographic): number {
  const key = `${cartographic.longitude.toFixed(6)},${cartographic.latitude.toFixed(6)}`;

  if (this.heightCache.has(key)) {
    return this.heightCache.get(key)!;
  }

  const height = this.viewer.scene.globe.getHeight(cartographic);
  if (height === undefined) return cartographic.height;
  this.heightCache.set(key, height);

  return height;
}

常见问题​

测量结果不准确​

原因：地形数据未加载、采样密度不足或坐标系统不匹配。

解决方案：

// 1. 确保地形数据已加载

  .then((terrainProvider) => {
    if (viewer.isDestroyed()) return;
    viewer.scene.terrainProvider = terrainProvider;
    // 还需等待测量区域的地形瓦片加载后，再开始测量。
  });

  const ray = this.viewer.camera.getPickRay(movement.position);

    cartesian = this.viewer.scene.globe.pick(ray, this.viewer.scene);
  }
}

// 如果还是没有，使用椭球体求交

  const ray = this.viewer.camera.getPickRay(movement.position);
  if (ray) {

  }
}

// 最后的保护措施

原因：实体未清理、事件处理器未销毁。

解决方案：

// 完整的清理函数
clear(): void {
  // 删除所有实体
  for (const id of this.measureIds) {
    try {
      this.viewer.entities.removeById(id);
    } catch (e) {
      console.warn('Failed to remove entity:', id);
    }
  }
  this.measureIds.length = 0;

  // 销毁事件处理器
  if (this.handler && !this.handler.isDestroyed()) {
    this.handler.destroy();
    this.handler = null;
  }

  // 清除缓存
  this.heightCache?.clear();

  this.bMeasuring = false;
  this.onMeasureEnd?.();
}

原因：实体过多、采样频率过高、地形数据复杂。

  // 清除旧的测量
  const oldIds = this.measureIds.splice(0, MAX_MEASURES * 5);
  for (const id of oldIds) {
    this.viewer.entities.removeById(id);
  }
}

注意事项​

  1. 地形数据：地表距离依赖已加载地形；面积只使用经纬度，不包含地形起伏
  2. 深度检测：启用 depthTestAgainstTerrain 确保正确拾取地形坐标
  3. 单位转换：注意距离单位（米/千米）和面积单位（平方米/平方公里）的转换
  4. 采样密度：地表距离测量时，采样点数量影响精度和性能，需要平衡
  5. 资源清理：测量完成后务必调用 clear() 方法清理资源
  6. 交互提示：建议提供明确的交互提示（左键添加点、右键结束）
  7. 浏览器兼容性：需要支持 WebGL 2.0 的现代浏览器
  8. 坐标精度：使用双精度浮点数避免精度损失
  9. 异步操作：地形瓦片异步加载，测量时读取当前已加载高度；缺失点使用端点线性插值
  10. 并发测量：切换模式会销毁旧事件处理器，并固定当前已确认的点
