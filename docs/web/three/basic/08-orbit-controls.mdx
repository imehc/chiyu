## 核心概念

- **OrbitControls**: 轨道相机控制器
- **角度限制**: minAzimuthAngle/maxAzimuthAngle 限制水平旋转，minPolarAngle/maxPolarAngle 限制垂直旋转
- **功能开关**: enablePan, enableRotate, enableZoom 控制交互功能
