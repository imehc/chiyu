## 核心概念

- **PointerLockControls**: 第一人称视角控制器
- **Pointer Lock API**: 锁定鼠标指针，隐藏光标
- **selector**: 指定触发控制的按钮
- **pointerlockchange**: 监听锁定状态变化事件
